# 收盘后自动预加载 K 线数据

## 方案一：手动执行（推荐首次使用）

1. 先启动 Flask 服务：
   ```bash
   python app.py
   ```

2. 在另一个终端执行预加载：
   ```bash
   python preload.py
   ```

3. 或者双击 `preload.bat` 直接运行。

## 方案二：Windows 任务计划程序（全自动）

### 步骤

1. **打开任务计划程序**
   - 按 `Win + R`，输入 `taskschd.msc`，回车。

2. **创建基本任务**
   - 右侧点击 `创建基本任务`。
   - 名称：`StockPreload`。
   - 触发器：选择 `每天`。
   - 开始时间：`15:30`（收盘后半小时）。
   - 操作：选择 `启动程序`。

3. **配置启动程序**
   - 程序或脚本：浏览选择 `python.exe`（一般在虚拟环境或系统 Python 路径）。
   - 添加参数：`preload.py`
   - 起始位置：选择项目文件夹路径（即 `app.py` 所在目录）。

4. **高级设置（可选）**
   - 勾选 `无论用户是否登录都要运行`（需要输入密码）。
   - 在 `条件` 选项卡中，取消勾选 `只有在计算机使用交流电源时才启动`。

5. **保存**
   - 点击确定，输入 Windows 密码。

### 注意事项

- 确保 Flask 服务已提前启动，或者任务计划里先启动 Flask 再运行 preload。
- 如果是 weekdays 执行，可以在 `触发器` -> `高级设置` 里勾选 `周一到周五`。

## 方案三：app.py 内置自动检测（最省心）

修改 `app.py`，在启动时自动检测是否收盘，如果是则自动预加载。
已内置 `/api/preload` 端点，可通过以下方式触发：

```bash
curl -X POST http://127.0.0.1:5000/api/preload
```
