# Stock Chart Analyzer - 项目整体情况

## 1. 项目概述

**Stock Chart Analyzer（股票图表分析工具）** 是一款面向 A 股市场的桌面端图表分析应用。基于 **Flask + ECharts** 架构，集成多源行情数据抓取、K 线与技术指标可视化、规则化技术分析预测等功能，通过 PyInstaller 打包为 Windows 原生可执行程序。

项目按目标操作系统拆分为两个完全独立、可分别构建的版本：

| 版本 | 目录 | 渲染引擎 | Python 运行时 | 主题 |
|------|------|----------|--------------|------|
| **Win11** | `win11/` | pywebview (WebView2 / Edge Chromium) | Python 3.13+ (uv) | Dark / Minimalist / HighEnd / Brutalist / Sync |
| **Win7** | `win7/` | PyQt5 + QWebEngineView | 社区魔改 Python 3.8.10 embeddable | 单一浅色主题 + Browser 回退 |

### 数据流

1. **云端采集** (`server_fetch_stock_data.py`)：在远程服务器上运行，通过 akshare（交易日历 + 股票列表）、baostock（历史 K 线）、腾讯财经 API（实时行情）填充 SQLite 数据库
2. **同步模式**：Sync 启动器从云端下载预构建的 SQLite 数据库到本地，设置 `STOCKCHART_SYNC_MODE=1`
3. **本地模式**：Flask 直接从新浪 / 腾讯 / baostock 实时拉取数据
4. **前端渲染**：JavaScript 调用 REST API 获取数据，使用 ECharts 渲染交互式图表

## 5. 核心功能模块

### 5.1 多源行情数据抓取 (`app.py`)

- **三源轮换**：新浪 → 腾讯 → baostock，带健康度熔断器 (`_ProviderHealth`)
- **反封锁策略**：10 个 UA 轮换、随机请求头、指数退避 + 抖动
- **增量预加载**：后台线程批量拉取，支持进度追踪，感知交易日历（硬编码 2026 A 股休市日）
- **连接复用**：requests.Session keep-alive

### 5.2 技术分析引擎 (`ml_module.py`)

> 注意：尽管文件名含 "ml"，实际实现为**规则化专家评分系统**，非机器学习模型。

- **特征计算**：30+ 技术指标（MA 比率、RSI、MACD、布林位置、动量、波动率、量比、时间特征）
- **评分预测**：MA 交叉(±2)、MACD 金叉(+3)、RSI 超买超卖(±2)、量比(+2)、动量(±2)、布林位置(±1) → 综合评分映射为「强烈看多 ~ 强烈看空」+ 置信度
- **选股筛选**：全市场扫描，返回 Top N 看多候选

### 5.3 云端数据采集 (`server_fetch_stock_data.py`)

- akshare 获取交易日历 + 股票列表
- baostock 逐只拉取历史 K 线（单线程保稳定，每 300 只主动重连）
- 腾讯财经 API 获取实时行情快照
- 增量更新、定期 flush、60 天旧数据清理、VACUUM
- 全部配置通过环境变量外化

### 5.4 前端 UI

- **四大功能模式**：条件选股、排行榜、代码输入、技术分析
- **交互特性**：双击股票打开 K 线、图表高度拖拽、字号四档切换（localStorage 持久化）、实时时钟、数据新鲜度标识、开市状态指示
- **Excel 导出**：SheetJS 客户端导出当前表格数据
- **Win11 四套主题**：Dark（暗色）、Minimalist（极简）、HighEnd（高端）、Brutalist（粗野主义）

### 5.5 安全加固

安全审计（2026-08-01）后，已完成以下修复：

- CSRF Token 保护
- CORS 白名单
- SQL 注入参数化
- SSL 证书验证
- Secret Key 随机化
- CSP / HSTS / X-Frame-Options 响应头
- 请求体大小限制 (16MB)
- Token Bucket 速率限制
- URL 协议校验（防 SSRF）
- Bandit 扫描：Win11 39→0，Win7 40→0

## 6. 构建方式

### Win11

```bash
cd win11
python build_win11_webview.py    # 生成 5 个 EXE（4 主题 + Sync）
```

前置条件：系统安装 WebView2 Runtime（构建脚本会自动检测注册表）。

### Win7

```bash
cd win7
python build_win7.py             # 生成 32 位 + 64 位 EXE
python build_win7_browser.py     # 生成浏览器模式 EXE
```

前置条件：准备好 `python38-amd64` / `python38-win32` 魔改运行时目录（见 `win7/WIN7_COMPAT.md`），内含 VC Runtime DLL。

## 7. 已知事项与待改进

| 类别 | 说明 |
|------|------|
| **代码重复** | win7/ 与 win11/ 后端源码完全复制，修改需同步两份；后续可抽取共享子模块 |
| **ML 模块命名** | `ml_module.py` 实为规则评分系统，`train_rf_model()` 并未训练模型；`ML_PLAN.md` 中的 XGBoost/LSTM/Transformer 均未实现 |
| **占位文件** | `math_utils.py` 仅含 `add()` 函数，`edgechromium.py` 仅含空 `setup_app()` |
| **SSL 验证** | Sync 启动器和云端采集脚本中使用 `CERT_NONE`，适用于内网/可信环境，公网部署需启用验证 |
| **交易日历** | 2026 年 A 股休市日硬编码在 app.py 中，每年需手动更新 |
| **构建产物** | 仓库中存在多个 dist_* 目录，反映大量构建迭代历史，建议清理 |
| **Win7 兼容性** | 依赖社区魔改 Python 3.8.10（官方 embeddable 在 Win7 有 bug），QtWebEngine 禁用沙箱和 GPU 加速 |
